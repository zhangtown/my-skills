# 技术标默认格式规范

来源：江苏交易场所登记结算有限公司网络入侵检测防御系统及安服项目投标（已验收通过）。

## 标题格式（Heading 1-4，自动编号 1 / 1.1 / 1.3.1 / 1.3.1.1）

| 级别 | 西文字体 | 中文字体 | 字号 | 加粗 | 颜色 | 段前 | 段后 | 行距 |
|---|---|---|---|---|---|---|---|---|
| 一级 | 等线（正文）DengXian | 黑体 SimHei | 16pt（三号） | 是 | 黑 | 17pt | 16.5pt | 2.41倍 |
| 二级 | 等线Light（标题）DengXian Light | 黑体 SimHei | 14pt（四号） | 是 | 黑 | 13pt | 13pt | 1.73倍 |
| 三级 | 等线Light（标题） | 黑体 SimHei | 14pt（四号） | 是 | 黑 | 13pt | 13pt | 1.73倍 |
| 四级 | 等线Light（标题） | 黑体 SimHei | 14pt（四号） | 是 | 黑 | 14pt | 14.5pt | 1.57倍 |

docx-js spacing/行距换算：
- 段前段后：twips = pt × 20（17pt→340，16.5pt→330，13pt→260，14pt→280，14.5pt→290）
- 行距（倍数）：line = 240 × 倍数，lineRule = AUTO（2.41→578，1.73→415，1.57→377，1.25→300）
- 字号：size = pt × 2（16pt→32，14pt→28，12pt→24）

## 正文（命名样式 0-正文）

- 西文字体：Times New Roman
- 中文字体：幼圆 YouYuan
- 字号：14pt（四号）
- 对齐：两端对齐（JUSTIFIED）
- 首行缩进：两个字符（`indent: { firstLineChars: 200 }`）
- 行距：1.25 倍

## 图片（命名样式 0-图格式）

- 对齐：居中
- 字体：Times New Roman，12pt（小四）
- 尺寸：A4 页边距 2.5cm 时可用宽约 16cm ≈ 596px@96dpi，图片按 16:9 等比缩放

## 图下标题（命名样式 0-图下标题）

- 西文字体：Times New Roman
- 中文字体：幼圆
- 字号：14pt（四号）
- 颜色：黑色
- 格式示例：`图1 设备功能模块组成图`（图号用 SEQ 域 `SequentialIdentifier("图")` 自动编号）

## 其他约定

- **全文纯黑**：所有 `<w:color>` = 000000（含样式表 Heading1-6、Hyperlink 默认色覆盖）
- **标题自动编号**：多级列表，`text` 占位符 `%N` 引用第 N 级计数器（1-based）：
  - level0: `%1`、level1: `%1.%2`、level2: `%1.%2.%3`、level3: `%1.%2.%3.%4`
  - 中文编号：level1: `%2、`、level2: `（%3）`、level0: `第%1章`
- **指标响应结构**：总体响应（总，功能概述段，批注框住此段）+ 详细阐述（分，2~4 段）
- **批注**：内容为 `【招标参数】<编号> <指标原文>`，作者为投标人，范围包裹总体响应段
- **承诺函**：每个单独一页（PageBreak），标题自动编号（如 1.4.1/1.4.2），含抬头/承诺正文/落款（右对齐：承诺单位盖章/签字/日期）
- **域更新**：`features: { updateFields: true }`，保证 Word/WPS 打开时 SEQ 图号、TOC 页码自动刷新

## 常见验收检查项

1. 页数 > 50（WPS 渲染后 `ComputeStatistics(2)`）
2. 批注数量 = 指标数量，且逐字一致（`scripts/verify_comments.py`）
3. 标题自动编号正确递增、跨章重置（渲染 PDF 抽查）
4. 图注连续编号（图1~图N），图片 16:9 不裁剪
5. 全文无省略号（若要求指标完整）、无【总体响应】（分）标记（若要求去除）
6. 全文纯黑（`scripts/check_black.py`）
