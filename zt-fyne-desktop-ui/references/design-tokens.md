# 设计令牌：Quiet Utility · 暗红主色变体

浅灰底 + 白色浮卡 + 唯一暗红主色 + 深灰渐变状态面板。**固定浅色**，不做深色模式。

> 令牌决定"颜色/字号/圆角/间距"；**各组件长什么样、几岁交给谁**见 `components.md`，
> 悬停/按压/焦点/禁用/选中这套状态机制见 `interaction-and-states.md`。两者共用本文件的令牌，
> 不要在组件代码里另写数值。

一句话记住这套设计：**底色拒绝大白（#EFF0F3），卡片才白，颜色只用一个暗红，圆角只有一个 8。**

## 色板

### 版面与卡片

| 令牌 | 值 | 用在哪 / 为什么 |
|---|---|---|
| `colBg` | `#EFF0F3` | 内容区底色。**拒绝纯白**——白卡要能浮起来 |
| `colSurface` | `#FFFFFF` | 卡片、输入框、菜单/弹层背景 |
| `colHairline` | `#E2E4E8` | 发丝线（分隔线，1px） |
| `colBorder` | `#D5D8DD` | 卡片/输入框边框 |
| `colBarBg` | `= colBg` | 自绘顶栏底色。曾是 `#E9EBEE`（与底色差一档，多出一条横带）和 `heroTop`（太黑），各被否一次 |

### 文字

| 令牌 | 值 | 说明 |
|---|---|---|
| `colText` | `#1F2328` | 主文字 |
| `colTextMid` | `#5A6169` | 次文字（说明、路径） |
| `colTextDim` | `#9AA0A8` | 弱文字 / 占位符 |
| 禁用文字 | `#6B7280` | 对白 **4.6:1**（原 `#8A9098` 只有 3.2:1）。连接期间这些字段是"锁定但要看"的信息，不是装饰 |

### 主色与状态

| 令牌 | 值 | 说明 |
|---|---|---|
| `colAccent` | `#A4243B` | 唯一主色（暗红）：主要按钮、链接、焦点 |
| `colAccentBg` | `#A4243B14` | 暗红 8% 底：悬浮/选中背景 |
| `colSelBg` | `#EAC6CE` | 文字选中高亮（近白在白卡上会隐形） |
| `colDanger` | `#D5382E` | 错误（比主色亮一档，和主色区分得开） |
| `colOK` | `#2E8B57` | 成功 |
| `colWarn` | `#C07A00` | 警告 |
| `colBarClose` | `#C42B1C` | 顶栏「✕」悬停底：Windows 惯用红，不用主色（避免和"关闭危险区"语义混淆） |

### 交互叠色

| 令牌 | 值 | 说明 |
|---|---|---|
| `colBtnHover` | `#00000024`（黑 14%，半透明） | 重要按钮（红 CTA）悬停：**叠在原底色上 = 底色加深** |
| `ColorNameHover` | `#E4E7EB` | 一般控件的悬浮底色（浅灰，白底上可见） |
| `ColorNamePressed` | `#D8DCE1` | 按压：比悬浮深一档，拉开层次 |
| `ColorNameFocus` | `#DEE2E8` | 激活/焦点高亮：菜单项、下拉选项、下拉展开底色 |
| `ColorNameDisabledButton` | `#F7F8FA` | 禁用按钮：淡到贴住卡片，**让"可用"比"禁用"更实** |
| `ColorNameShadow` | `#1F232812` | Fyne 自己的阴影色（注意：窗口投影不走这里，见 windows-chrome） |

**为什么 CTA 悬停不能用不透明的 `ColorNameHover`**：blend 时会把红色整个罩成灰，
在深色 hero 面板上看着像按钮失效。RemoteNet 为此在 vendored 的
`vendor/fyne.io/fyne/v2/widget/button.go` 加了 `ButtonHoverDeepColorName`——
半透明叠色是唯一能让"加深"对任意底色都成立的做法。

### 深色状态面板（hero）

| 令牌 | 值 | 说明 |
|---|---|---|
| `heroTop` → `heroBottom` | `#2C313A` → `#15171C` | 垂直渐变（上浅下深） |
| `heroText` | `#F2F3F5` | 面板主文字 |
| `heroTextSub` | `#9BA3AD` | 面板次文字 |
| `heroAccent` | `#E04B5E` | 面板上的强调色：**比主色亮一档**，保证深底上的对比 |

深色面板是这套浅色设计里唯一的"重点区"：状态、流量、主操作放这里。
它**通栏**（左右各比白卡宽 5px，即不被 `cardPadH` 内缩），这是刻意的——别给它补左右 padding。

## 字号与圆角

| 令牌 | 值 | 说明 |
|---|---|---|
| 正文 `SizeNameText` | 14 | 默认 |
| 副标题 `SizeNameSubHeadingText` | 15 | 卡片标题 |
| 说明 `SizeNameCaptionText` | 12 | 辅助说明 |
| 列表行 / 菜单文字 | 13 | 等宽同色，**两者必须一致**（菜单和「连接明细」列表放一起比较时不能有落差） |
| 圆角 `InputRadius` / `ButtonRadius` / `SelectionRadius` | **8** | 统一 8。曾出现输入框 8、选中 5 的"双标准"，已统一 |
| 行距 `SizeNamePadding` | **5** | 所有容器行距的唯一来源（见 layout-and-interaction） |
| 分隔线 `SeparatorThickness` | 1 | |

菜单/下拉弹层还有一组"密度"补丁（`vendor/fyne.io/fyne/v2/widget/menu.go` / `menu_item.go`）：
菜单项垂直留白 8→4px、行间距 5→2px、高亮块内缩 5→1.5px（块高保持 25px）。
这是为了让菜单密度接近系统菜单——**要动就整体一起动，别只改一处**。

## 加新样式时的判断顺序

1. 能不能用现有令牌？（能就别加。）
2. 是不是某个令牌的别名？（如 `colBarBg = colBg` —— 别名要写明"为什么相同"。）
3. 真的需要新色？给出它的**对比度依据**（如禁用文字 4.6:1）和**与相邻色的区分依据**
   （如 danger 比 accent 亮一档），而不是"看着好看"。
4. 半透明叠色优先于不透明覆色：任何"悬停/选中/按压"都应该是叠在原底色上，这样换底色不会破。
