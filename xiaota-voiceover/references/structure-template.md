# 3分钟时间轴骨架

## 语速基准

来自案例2的真实 SRT 数据：**1172字 / 3分38秒 = 323字/分**。

| 目标时长 | 目标字数 |
|---|---|
| 2分30秒 | 800–830 字 |
| **3分钟** | **950–1100 字** |
| 3分30秒 | 1100–1150 字 |

用户说"3分钟左右"，落在 950–1100 字。**宁可偏短也不要偏长**——口播稿念起来总比看起来长，超了会显得拖。

---

## 时间轴

### 0:00–0:20 ｜ 钩子（约100字）

**直接从最扎眼的画面、最离谱的数字或最荒谬的对比切入。不要任何铺垫，不要自我介绍。**

可选的开场动作：

- 具体画面型："先给大家看一张图。"→ 描述画面里那个不对劲的细节
- 数字冲击型："一个县级融媒体中心 / 花了将近100万 / 引进了一位国际传播人才"
- 标题堆叠型：连念三条新闻标题，然后一句冷评（"人在家中坐，锅从天上来"）
- 时间线型："先给大家看一张时间线图。"

钩子段落里通常埋一个悬念问句收尾：**"你猜插图画成什么样了？""他到底传播的是什么？"**

### 0:20–0:32 ｜ 报名字 + 预告（约60字）

```
大家好，我是小踏。
今天这期视频，
你耐心看完，
就知道……（一句承诺，点出要揭的那层皮）
```

案例2原文："今天这期视频你耐心看完，就知道有些人嘴里喊着文化交流，背地里干的是什么买卖。"

预告要**给利益**，不是给目录。不要写"今天我们从三个方面来分析"。

### 0:32–1:20 ｜ 第一段：揭开落差（约250字）

把"表象"讲足（让观众真的信了），然后**用一句短句翻盘**。

翻盘信号句："直到……""反转来了。""但你注意到没有——"

翻转之后立刻上第一批硬事实。这一段结束时，观众应该已经明白"事情不是我以为的那样"。

### 1:20–2:05 ｜ 第二段：扩大战线（约250字）

把同类案例横向铺开，证明这不是孤例。用**同构排比**（见 style-guide 第六条）：

> 郑州一个健身房12名外籍教练
> 地方科技局把印度餐饮员工列进人才名单
> 人民网发文帮助外籍青年融入中国
> ……

这一段最容易变成流水账。**关键是排比之后要有收拢句**，把这一堆事实总结成一个模式：

> 一边限制自己人，一边对外敞开大门。你说这正常吗？

如果观众可能会觉得你小题大做，这里可以插入"自我应答公式"（style-guide 第五条）来消化质疑——**但素材分量本身够重时不要用**，硬套会显得在自问自答。

### 2:05–2:35 ｜ 第三段：升维（约150字）

从具体事件跳到它代表的东西。这里是整期的情绪最高点，也是**最可能被截图传播的15秒**。

技术动作：

1. 借他人之口引入一句格言（"有位网友说了一段话，我印象很深"）
2. 给一个对仗的短句（"开放不是坏事，但开门不等同于拆墙"／"规矩是用来保护自己人的"）
3. 回扣开头的那件事，形成闭环（"回到敦煌这件事……"）

### 2:35–3:00 ｜ 收尾（约100字）

```
好了，这期视频就聊到这儿。
（可选的最后一句价值重申）
我是小踏。
喜欢的朋友点点关注，一键三连支持一下。
咱们下期视频再见。
```

收尾前通常还有一次**底线陈述**：不是上纲上线，是在守一条底线——然后把底线用一句大白话说出来（"孩子们翻开的那本书，必须是干净的。每一页都是。"）。

## 节奏指标（自检时核对）

| 指标 | 目标 | 为什么 |
|---|---|---|
| 平均句长 | 9–14 字 | 案例实测 9.2–14.3 字。超过就往15+字跑，念起来开始费劲 |
| 最长句 | ≤ 33 字 | 案例最长 33 字。再长就要断句 |
| 短句占比（≤10字） | ≥ 40% | 案例一41%、案例2是70%。短句是节奏感的来源 |
| 换行 | 一行一句 | 文字稿的换行＝口播的停顿 |
| 问句数量 | 8–15 处 | 案例一13、案例三15。少于8处会显得平 |
| 反转 | 至少1次 | 没有翻盘就不是小踏的结构 |
| 硬事实密度 | 每100字≥1个 | 具体数字/人名/机构/书名 |
| 字数 | 950–1100 | 对应3分钟 |

## 结构上的三个常见失败

1. **开头太慢**。花15秒说"最近有件事引发了广泛关注"。→ 删掉，直接从画面/数字开始。
2. **只有一排事实，没有落差**。观众听完知道发生了什么，但不知道"所以呢"。→ 回到第二步，找到那条"看起来是A其实是B"。
3. **结尾在复述**。把前面说过的再总结一遍。→ 结尾应该是**升维**，不是复述。找一个比这件事更大的东西。
