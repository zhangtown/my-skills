# 盖章签字前整体标书自检表（模式 B）

> **适用时点**：商务技术合稿完成、打印签章**之前**。范围是**全本**。
> **这是最后一个能低成本消除废标风险的时点**——打印盖章之后就只剩"重打重盖"这一条路。
>
> 模式 B 的独特产出是两份东西：
> ① **逐页签章清单**（谁在哪页盖什么章）；
> ② **文件外事项打钩表**（电子件里查不到、但每一条都是废标级）。

---

## 零、先做三件事

1. **确认版本**。跟技术标/商务标的最后一版做 hash 比对，确认手里这份是最新的合稿版。
2. **确认份数与袋数**。正本 1 份 + 副本 N 份（常见 5 份）+ 电子版 U 盘 N 个。正副本**封面必须分别标注"正本"/"副本"**。
3. **取出本项目无效投标情形清单**（见 `invalid-bid-clauses.md`），后面逐条对照。

---

## 一、逐条对照无效投标情形

做成表，每条给三个状态之一：**通过 / 命中 / 无法从电子件核实**。

```markdown
| # | 条款（招标原文） | 要求 | 投标文件实际 | 位置 | 判定 |
|---|---|---|---|---|---|
| 1 | 未按招标文件规定的要求密封、签署、盖章的 | 相应位置须签署并盖章 | ______ | P___ | 待确认 |
| 2 | 不具备招标文件中规定的资格要求的 | ______ | ______ | P___ | 通过 |
| 3 | 报价超过预算金额或者最高限价的 | ≤ ______ 元 | ______ 元 | 开标一览表 | 通过 |
| … | | | | | |
```

⚠️ **"无法从电子件核实" ≠ "没问题"**。单列进第七节的打钩表，不要混在"通过"里。

---

## 二、签章清单（模式 B 的核心）

### 电子件里能查到"哪些位置需要章"

用 `scripts/probe_docx.py --only seal` 定位所有签章栏位并判断该段落**有没有图片**。

**这是纯文本审查 100% 会漏的一类问题**：公司名是用字打上去的，文本层看起来"填了"，但一个真章都没有。

| 位置（实测清单） | 需盖 | 需签 |
|---|---|---|
| 投标函 | 单位公章 | 法定代表人（或授权代表） |
| 开标一览表（装订本 + **单独密封本**） | 单位公章 | — |
| 分项报价表 / 报价明细表 | 单位公章 | 授权代表 |
| **法人授权委托书** | 单位公章 | **法定代表人** ← 最优先 |
| 投标承诺书（常被定义为实质性条款） | 单位公章 | 授权代表 |
| 保证金退还信息表 | 单位公章 | — |
| 履约能力承诺函 / 无重大违法记录声明函 | 单位公章 | 授权代表 |
| 商务条款偏离表 | 单位公章 | 授权代表 |
| 技术要求响应/偏离表 | 单位公章 | 授权代表 |
| 售后服务承诺书 / **驻场服务承诺书** | 单位公章 | 授权代表 |
| 中小企业声明函 / 本国产品声明函（**专门面向中小企业时必须提供**） | 单位公章 | — |
| 节能产品信息表 / 环境标志产品信息表 | 单位公章 | — |
| 资格证明文件：营业执照、财务报表、纳税凭证、社保凭证 | 复印件加盖公章 | — |
| 业绩证明材料：合同、中标通知书、验收报告复印件 | 复印件加盖公章 | — |
| **▲ 项证明材料**（产品彩页/说明书/检验报告复印件） | **逐页加盖公章** | — |
| 封面 / 封口 | 公章、**骑缝章** | — |

### 实测案例

- **226 页的标书，13 处签章位置全部为空**——投标函、开标一览表、报价明细表、履约能力承诺函、无重大违法记录声明函、授权委托书、保证金采集表、汇款凭证、商务偏离表、技术偏离表、售后服务承诺书。签章栏里填的是**打字文本**，段落内图片数 = 0。
- **38 张▲项材料一张章都没有**（红色连通域分析：最大红块要么是 1×13 px 的细线，要么是界面里的橙色高亮框）。
  而招标评分表明确要求"（如为复印件，需要**加盖供应商公章**）"。
- **《投标承诺书》落款栏空白**，而招标格式注写"本'投标承诺书'为**实质性条款**，未按要求提供按**无效投标**处理"。

### 盖章本身的形态要求

| 要求 | 说明 |
|---|---|
| 位置 | 压住单位名称/落款，规范做法是**压字盖章** |
| 骑缝章 | 多页文件、封套封口处 |
| 正副本 | 副本同样要盖（或按招标要求；不确定就都盖） |
| **原件 vs 复印件** | 招标写"**原件**"的，彩色打印的复印件**不算** |
| 手写签字 | 用**黑色或蓝黑色**签字笔；不要用红笔/铅笔 |
| 修改处 | 招标常规定"改动处需由授权代表签名或加盖公章" |

## 三、表格与用语

| 检查项 | 判据 | 实测 |
|---|---|---|
| 偏离表填写用语 | 招标注只允许 `响应` / `正偏离` / `负偏离` | 全文 **79 处"无偏离"**（67 行技术表 + 12 行商务表），招标从未定义该词 |
| 表格栏目名称与顺序 | 与第六章模板一致 | 业绩表"合同金额"与"业主单位及联系电话"两栏对调 |
| 页码引用 | ▲项"证明材料所在页码"要能翻到材料 | 12 项▲页码全指向自述章节，彩页在第 209–221 页却没被引用 |
| 表格是否被污染 | 偏离表只放条款响应 | 商务偏离表 13 行里 **7 行是评分索分文案**（"可满足本项最高 2 分的评分要求"） |
| 项目编号 | 含括号内的 SEU 编号，全篇一致 | 漏写 `(SEU-ZB-260675)` |
| 日期 | 各处签署日期一致、不早于招标文件日期、不晚于投标截止日 | 模板留空处被**预印成固定日期** |
| 金额 | 大小写一致、三处报价一致 | 开标一览表 / 附件 / 报价明细表 |
| 落款格式 | 与模板一致 | **两套写法混用**：A 式`供应商名称（公章）：` vs B 式`供应商名称：/供应商公章：/日期：` |
| 目录 ↔ 评标索引 ↔ 正文页码 | 三向对账 | 实测一致 ✔ |
| 页码 | 有连续页码 | 实测 471 页 ✔ |

### 商务条款偏离表只覆盖部分条款？

实测：只响应了第四章"其他商务要求"5 条，而第二章《合同格式》有 9 条。违约责任、质量标准、验收、合同解除未逐条响应。
而无效投标情形第 (4) 条用的是"《合同格式》"这个**更宽口径**。

→ 判断口径：以招标原文的引用范围为准。若招标写"投标人应对《合同格式》全部条款进行响应"，则 9 条都要有。

## 四、文档痕迹与隐私

电子标时代，评标系统和外部质疑者都会看文件属性。目标是**消除"同源"口实和隐私泄露**。

| 查点 | 位置 | 实测踩过的坑 |
|---|---|---|
| 作者 / 最后修改者 / 公司 | `docProps/core.xml`、`docProps/app.xml` | 真名"凉月"从 v36 留到 v37；两家陪标的 creator 与 lastModifiedBy 同为占位串「【待填：投标人全称-经办人姓名】」且 `revision` 都是 12 → **同源口实** |
| 编辑会话指纹 rsid | `word/settings.xml` | 一份文件出现 1742 条 rsid（正常数十条）= 长期反复改稿 |
| 批注作者 | `word/comments.xml` 的 `w:author` | 各家必须互不相同 |
| 环境残留 | 全 XML | MAC 地址、硬盘序列号、`C:\Users\<真名>\…`、机器名 |
| **电子表格痕迹** | `.xlsx` 自身 | 隐藏工作表、单元格批注作者、共享工作簿修订记录、外部链接路径、透视缓存残留数据、自定义文档属性 |
| 内部占位符 | 正文 | `【待填】`、`【响应位置】`、`【待填·见批注】`、`[公司名]`、`XXX` |
| 外部链接残留 | 正文 | 实测：供应商资料里留着 `https://server.zol.com.cn/1248/12484503.html`（中关村在线报价页） |
| 上传痕迹 | 标书之外 | 电子评标系统普遍记录上传 IP；**MAC/硬盘序列号相同被明文写入无效投标条款** |

**多份文件同批投递（主标＋陪标）时，必须逐份做"两两交叉"比对**，而不是只看单份是否干净。

### 编制环境纪律

实测用户原话：

> "因为是要上传电子标，所以要审核 IP、MAC、作者之类的，**所以要新建一个空白的文档**，把两份合在一起。"

→ 每家的投标文件应在**独立环境**（不同机器/不同账户）编制；新建空白文档再合稿，避免继承模板的 rsid 与作者。

## 五、内容自相矛盾

找法是**交叉一致性**：同一事实在文档不同位置的说法对不对得上。

| 类型 | 实测案例 | 后果 |
|---|---|---|
| 同事项两页内矛盾 | 偏离表"属于最新一期《节能产品政府采购品目清单》范围内产品……持有节能产品认证证书"；两页外节能产品信息表"归属编码"填"**无**"，自注"服务器未列入清单" | **虚假材料 → 废标**（不是扣分） |
| 声称已做实际没有 | "已加盖单位公章"（没盖）；"另附《驻场服务承诺书》**原件**，随投标文件同步提交"（文件里没有这份）；"同时提供原件"（只有复印件） | 失实陈述 / 实质性条款未响应 |
| 承诺自相矛盾 | 承诺表"1 年"，正文三处"驻场期限**根据项目需求调整**"；而招标要求"承诺书**应明确**驻场期限及驻场时段" | 实质性条款负偏离 |
| 响应与实物不符 | 以"单盘容量高于要求"为由对接口/尺寸不符的配置声明"无偏离"；用"自研互连**对标** 2 条 UPI"置换"**具备**"；回避不写实际超标的功耗（TDP） | 虚假材料 / 技术参数负偏离 |
| 报价类矛盾 | 保证金回单附言编号与招标给出编号差一位 | 轻微，但建议更正 |

**处理原则**：如实列示负偏离 > 修正措辞继续回避。主动声明一条负偏离通常只扣 0.2 分；被评委发现隐瞒，性质就变了。

## 七、文件外事项打钩表（电子件里查不到，但每一条都是废标级）

## 八、整改优先级口径

- **P0 必废**：命中无效投标情形、实质性条款负偏离、缺必交文件、缺章缺签。**不补不能交。**
- **P1 丢分**：▲项材料形态/清晰度/盖章/对应关系缺陷、加分项材料缺失、栏目与用语不符。
- **P2 瑕疵**：栏目错序、措辞、编号不一致——零成本但不改也不致命。
- **待确认**：无法从电子件核实的（单列，不当"通过"）。

⚠️ 改动前先看招标的"改动处需由授权代表签名或加盖公章"条款：
**要么每处签章，要么整表重排不留涂改痕迹。** 这也是为什么不能把所有 P2 都改掉——改多了反而增加风险。
