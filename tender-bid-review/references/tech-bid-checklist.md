# 技术标自检表（模式 A）

> **适用时点**：技术标成稿、移交给商务侧合稿**之前**。
> **不碰**：投标函、开标一览表、报价、分项报价表、资格证明、营业执照、财务报表、纳税社保、
> 法人授权委托书、保证金凭证、**商务条款偏离表**——这些归商务侧，越界修改会打乱分工。
>
> 技术标阶段的产出不是"一份完稿"，而是 **① 一份改好的技术标正文 + ② 一份交给商务侧的遗留项交接清单**。

---

## 一、技术条款逐条响应

| # | 检查项 | 判据 | 常见问题 |
|---|---|---|---|
| 1 | 招标技术要求的**每一条**都有对应行 | 招标"采购需求·技术要求"条目数 = 偏离表行数 | 漏行、把两三条合成一行 |
| 2 | "响应/偏离情况"栏用**招标规定的词** | 招标注通常只允许 `响应` / `正偏离` / `负偏离` 三个词 | **实测：67 行全部填"无偏离"**（招标从未定义该词） |
| 3 | "投标文件技术指标情况"栏**不照抄招标原文** | 招标常写"直接拷贝招标文件技术要求的按照无效投标处理" | 整段复制的风险高于只写"响应"两字 |
| 4 | 每个数字都**≥**指标 | 逐一比对，含"不少于""≤""支持 N 路" | 用"高于要求"掩盖接口/尺寸不符 |
| 5 | 页码引用指向**正确的材料位置** | 翻到该页应能看到对应证明材料 | **实测：12 项▲的页码全指向自述章节，彩页实际在第 209–221 页** |
| 6 | 表格**未被污染** | 偏离表只放条款响应 | 混入"可满足本项最高 2 分的评分要求"等索分文案 |
| 7 | 栏目名称与顺序与招标模板一致 | 招标写"按……格式、内容、**顺序**制作" | **实测：业绩表"合同金额"与"业主单位及联系电话"两栏对调** |

### 品牌 / 型号 / 制造商 / 产地

- 供货一览表与分项报价表**逐格填满**：产品名称、品牌、规格型号、**生产企业名称**、**生产企业地址**、产地、数量。
- 招标原文（常见）："供应商应根据上表要求**逐一说明**投标货物名称、品牌、规格型号、产地、技术参数等，**否则，按照无效投标处理**"。
- ⚠️ 各投标人的**核心产品品牌必须互不相同**——综合评分法下同品牌按一家计算（非单一产品项目看核心产品）。

### 人员与业绩

- 人员证书：注意"**一人多证不得分**"类限制——同一人持多张证只算一张，不要指望堆人凑分。
- 社保证明：**查询期要覆盖招标要求的时间窗**。实测踩过：证明是 5 月打印、窗口 202603–202605，距 10 月开标已过近 5 个月，窗口偏紧 → 换新的。
- 业绩：合同金额、签订时间、用户单位、联系人电话逐栏核对；必要时附**公司名称变更说明材料**（名称变更会让业绩主体与现名不符）。

## 二、▲ 项证明材料（技术标的核心战场）

▲ 项是**扣分线不是废标线**（常见每条扣 1.3–2.5 分），但它有一条隐藏硬规定：
**材料形态不符 = 即便功能真的满足，该项也拿不到分。**

招标通常只认三种形态：**第三方机构检验报告 / 产品说明书 / 产品彩页**（复印件须加盖投标人公章）。
**投标人自述的技术方案不算。**

逐项核验六件事——**做一个 N 行 × 6 列的矩阵，缺一不可**：

| 维度 | 判据 | 实测踩过的坑 |
|---|---|---|
| **形态** | 是招标认的三种之一吗 | 用自述方案、用界面截图代替产品彩页 |
| **齐备** | N 个▲就有 N 份材料 | 招标要求**逐项**提供，共用一张图不行 |
| **清晰度** | 有效 DPI ≥ 150（见下） | 12 项▲统一 111 dpi，同文档业绩合同 284 dpi |
| **盖章** | 复印件加盖投标人公章 | 38 张▲材料**一张章都没有**；签章栏只打了公司名的字 |
| **对应关系** | 图文一一对应 | ①一张图被两个▲项共用 ②同一张图在同一项里贴两次 ③两张图像素级雷同（MAD=0.01）实际只有一张 |
| **数量级自洽** | 图上数得出指标要求的数量 | 指标"不少于 20 个案例"，截图只数得出约 7 个案例卡 |

### 有效 DPI —— 算的是"打印出来多大"，不是文件多少像素

```
有效 DPI = 图片像素宽 ÷ 文档内显示宽度（英寸）
         = 像素宽 ÷ (wp:extent 的 EMU ÷ 360000 ÷ 2.54)
```

`wp:extent` 是段落的显示尺寸（EMU；1 英寸 = 914400，1 cm = 360000）。用 `scripts/img_dpi.py` 批量算。

| 有效 DPI | 结论 | 处置 |
|---|---|---|
| ≥ 300 | 印刷级 | 不动 |
| 200–300 | 良好，小字清楚 | 不动 |
| 150–200 | 及格 | 不动 |
| 120–150 | **偏弱**——数字、英文、小号字发虚 | 重出 |
| < 120 | **不合格** | 必须重出 |

直观换算：正文汉字原高 13 px、显示宽 14.65 cm 时，打印后字高仅 **约 3.0 mm ≈ 8.4 pt**。

**补救优先级**：重新导出矢量（PDF / EMF）> 重新截图 ≥ 200 dpi > 原图放大。
⚠️ **原图放大量本无用**——放大不能凭空造出细节。**先算"重出后 DPI 会不会真的提高"再决定要不要返工**，否则白费功夫。

**顺带把同文档其它材料的 DPI 也算出来当参照。** 实测一份标书里：▲材料 111 dpi 垫底、项目人员证书 155–161、财务审计报表 206、节能/环境标志证书 206、业绩合同 284。这个**对比本身**就是说服用户返工的最有力论据，比"建议提高清晰度"有用得多。

### 截图纪律

- **必须在白板（无批注）版本上截图**——带批注的版本会把内部标注一起截进去。批注只用于自己定位偏离表页码。
- 规格：**1920×1080**、界面文字清晰可读、不模糊不重叠、符合企业级后台软件视觉规范。
- 图注用带域编号（SEQ 域）的图注，标题全部自动编号。
- **不要从别的章节复制粘贴图片** —— 这是图文错位最主要的来源。
  实测错位：▲2.22（指标 8）下第一张截图其实是"日志提取工具"；指标 7 下混入"试卷导入/导出"（属指标 8）；指标 1 与指标 2 都引用了说明书同一张图。

## 三、技术方案正文

| 检查项 | 说明 |
|---|---|
| 内部占位符清零 | `【待填】`、`【响应位置】`、`【待填·见批注】`、`[公司名]`、`XXX`。**实测：41 处【响应位置】未填，而版本只改了文档属性、正文一字未动** |
| 软件/产品名称拼写 | 实测：`ClassicMLLibraries` 缺空格 |
| 字体字号统一 | 实测：曾出现三种字体；应统一（如宋体五号） |
| 表格对齐 | 两端对齐优于居中（观感） |
| 列宽按文字量规划 | 避免挤成一列 |
| 术语一致性 | 同一东西全篇同一叫法（如"R5210 G11"不要在别处写成"R5210"） |
| 图文一一对应 | 见上节 |
| 删除别人的批注/修订 | 终稿不能带内部批注，尤其带真名或内部沟通内容的 |

## 四、服务承诺类（技术标里最像"实质性条款"的部分）

商务侧通常管商务条款，但**售后/驻场/培训**这些服务承诺常由技术侧起草，而它们恰恰是实质性条款。

- **驻场**：招标若写"投标文件中**须**提供加盖单位公章的驻场服务承诺书**原件**，承诺书**应明确**驻场期限及驻场时段"——那就要：
  1. 有**独立文件**（不是在正文里写一段话）；
  2. 是**原件**（彩色打印的复印件不算）；
  3. **加盖单位公章**；
  4. 明确写**期限**和**时段**。
  ⚠️ 实测踩坑：承诺表写"1 年"，正文三处却写"驻场期限**根据项目需求调整**"——**自相矛盾**，而招标要求的是"**明确**"。
- **驻场人员**：招标常要求"驻场人员不少于 N 名，未经采购人书面同意不得擅自更换"——承诺书要相应写明。
- **交货期 / 质保期**：必须与招标要求一致（"报价方式、付款方式、合同履行期限、质保期未响应招标要求的"= 无效投标）。
- **培训**：课时数要覆盖招标要求，并在方案里能数得出来。

> 商务条款常附注："**注：商务条款为实质性条款，不接受负偏离。**"——这种项目的驻场/交货期/质保期一律不得负偏离。

## 五、交给商务侧的遗留项交接清单（模板）

技术标阶段结束时，把下面这张表交给商务侧，比替他做完更有用：

```markdown
# 技术标遗留项交接清单 · <项目名>

## 必须先由商务侧确认才能定稿的
- [ ] 核心产品品牌是否与其它投标人重复（同品牌按一家计算）
- [ ] 保修年限 / 供货期 / 报价口径是否最终确定（影响技术方案的表述）
- [ ] 我方主体名称（用于证明材料上的公章）

## 技术侧已做完、需商务侧盖章的
- [ ] ▲项证明材料复印件 ______ 页，共 ___ 处，逐页加盖公章
- [ ] 《驻场服务承诺书》原件（含期限与时段）______
- [ ] 各承诺函落款栏

## 技术侧无法处理、需商务侧/厂商支持的
- [ ] 节能产品认证证书 / 环境标志产品认证证书（向厂商索取）
- [ ] 《节能产品信息表》《环境标志产品信息表》
- [ ] 厂商盖章版规格书、原厂配置承诺函

## 合稿后请回头确认（易被整章删除）
- [ ] 证书章节仍在（实测：合稿时另一团队写的"环境标志产品认证证书""节能产品认证证书"两节被整个删掉）
- [ ] ▲项页码引用仍指向正确位置
```

## 六、技术标模式**不做**的事

- 不填商务条款偏离表。实测用户原话："商务侧去搞的东西，我们就不要画蛇添足，比如说商务偏离表，这个我们就不要填了。"
- 不填报价、开标一览表、分项报价表。
- 不碰资格证明文件（营业执照、财务报表、纳税社保、法人授权委托书、保证金凭证）。
- 不为"看起来完整"而补写没有依据的内容。
